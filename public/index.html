Manuscript ingestion (Layer 2 / Layer 3 memory)
Bulk import (whole manuscript, auto-split by chapter)

Paste an entire manuscript. Lines like "Chapter 1", "Chapter Two — Homecoming", or "CHAPTER 9:" are detected automatically and split into separate chapters. Runs as a resumable background job — one chapter is chunked and embedded per step, so even a very large manuscript processes safely without one long-lived request. Closing this tab pauses it; reopening offers to resume right where it left off.

Banned Terms (Ghost Editor)

Ban a word or phrase for this Book ID and Hanami will never produce it again — checked against every full generation, and any paragraph that contains a banned term gets silently regenerated (with verification, up to 3 attempts) before you ever see it. There's no free "erase from vocabulary" shortcut for this — confirmed against the real API that generation-time token suppression isn't honored and wouldn't safely target whole words anyway — so this only activates (and only costs the extra regeneration time) for books that actually have banned terms set.
