# Skill research briefs

Eight research briefs that are the source material for the backend "skills"
(see the task that introduced this folder). Each is one "school" file from a
research round commissioned for a different book's outlining tournament
(Chapters 71 to 75 of *The Lycan King's Plump Obsession*), so:

- The general craft and market findings in each are portable. Use them.
- The closing section of each ("What this means for Chapters 71-75 of this
  book") and every chapter-number or character-specific reference is about that
  other book. It is NOT about the book this backend serves. Don't carry it
  across; adapt the underlying principle instead.
- `08_current-market.md` is dated November 2026 and contains time-sensitive
  figures; treat it as a snapshot and flag staleness.
- These files are reference material, not runtime code. Nothing reads them at
  run time.

| File | Subject |
| --- | --- |
| `01_werewolf-shifter-romance.md` | What werewolf/shifter romance readers are actually paying for: the bond, the alpha, rejection and reversal, claiming, the full moon |
| `02_romance-craft.md` | The romance arc, tension and release, why "will they or won't they" dies, keeping lovers apart honestly |
| `03_erotic-high-heat.md` | Writing high-heat scenes: purpose, escalation, consent and dark dynamics, size difference, the curvy heroine |
| `04_serial-platform-plotting.md` | Pay-per-chapter serials: the chapter as the unit of sale, chapter-end pull, arcs, mid-run sag |
| `05_secrets-and-reveals.md` | Secrets that pay their way, reveals that land, thread count, dramatic irony |
| `06_fiction-fundamentals.md` | Desire, cause and effect, set-up and payoff, escalation, surprise, running a large cast |
| `07_anti-slop.md` | What reads as formula or machine-made, and what gives a book its own feel |
| `08_current-market.md` | The current werewolf-romance market and where a premise sits in it |
